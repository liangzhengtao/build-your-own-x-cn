> 从零开始，用 C++ 和 SDL2 构建一个 2D 游戏引擎核心框架。

## 📋 项目简介

游戏引擎是游戏开发的基石。通过从零构建一个游戏引擎，你将深入理解游戏循环、渲染管线、物理模拟、音频系统、场景管理等核心概念。

本教程将引导你构建 `MiniEngine`——一个支持以下功能的 2D 游戏引擎：
- 游戏主循环（Game Loop）
- 实体组件系统（ECS）
- 2D 精灵渲染
- 简单物理引擎（碰撞检测）
- 输入管理系统
- 音频播放
- 瓦片地图（Tilemap）

## 📖 核心概念解释

### 1. 游戏循环

游戏循环是引擎的心脏，每秒运行 60 次（或更多）：

```
┌──────────────────────────────────────────────┐
│               Game Loop (60 FPS)             │
│                                              │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  │
│  │ 处理输入  │→│  更新逻辑 │→│  渲染画面 │  │
│  │ (Input)  │  │ (Update) │  │ (Render) │  │
│  └──────────┘  └──────────┘  └──────────┘  │
│       ↑                                │     │
│       └────────────────────────────────┘     │
│                                              │
│  每帧耗时: ~16.67ms (60fps)                   │
│  固定时间步长: Δt = 1/60 秒                   │
└──────────────────────────────────────────────┘
```

### 2. 实体组件系统（ECS）

```
传统面向对象:
  class Player : public GameObject { ... }  ← 继承层次深
  class Enemy  : public GameObject { ... }

ECS 架构:
  Entity (只是一个 ID)
    ├─ Component: Position {x, y}
    ├─ Component: Sprite {texture, rect}
    ├─ Component: Velocity {vx, vy}
    └─ Component: Collider {width, height}

  System: MovementSystem    → 处理所有有 Position + Velocity 的实体
  System: RenderSystem      → 处理所有有 Position + Sprite 的实体
  System: CollisionSystem   → 处理所有有 Position + Collider 的实体
```

### 3. 渲染管线（2D）

```
游戏对象
  │
  ▼
精灵（Sprite）
  ├─ 纹理（Texture）
  ├─ 源矩形（Source Rect）← 精灵表中的区域
  └─ 变换（位置、旋转、缩放）
  │
  ▼
渲染器（Renderer）
  ├─ 清屏
  ├─ 绘制背景/瓦片地图
  ├─ 绘制精灵（按 Z-order 排序）
  ├─ 绘制 UI
  └─ 交换缓冲区（呈现）
```

### 4. 2D 物理与碰撞检测

```
AABB（轴对齐包围盒）碰撞检测:

  ┌─────┐         ┌─────┐
  │  A  │         │  B  │
  └─────┘         └─────┘

  分离轴检测:
  if (A.maxX < B.minX || A.minX > B.maxX) → 无碰撞 (X 轴分离)
  if (A.maxY < B.minY || A.minY > B.maxY) → 无碰撞 (Y 轴分离)
  否则 → 碰撞！

  碰撞响应:
  找到最小穿透方向，将物体推开
```

### 5. 瓦片地图

```
  Tileset（瓦片集）:
  ┌──┬──┬──┬──┬──┐
  │草地│泥土│水面│石头│树木│
  └──┴──┴──┴──┴──┘

  Tilemap（瓦片地图）:
  ┌──┬──┬──┬──┬──┬──┐
  │草地│草地│草地│草地│草地│草地│
  ├──┼──┼──┼──┼──┼──┤
  │草地│树木│草地│草地│水面│水面│
  ├──┼──┼──┼──┼──┼──┤
  │草地│草地│石头│草地│水面│水面│
  ├──┼──┼──┼──┼──┼──┤
  │草地│草地│草地│草地│草地│草地│
  └──┴──┴──┴──┴──┴──┘

  地图数据: [[0,0,0,0,0,0], [0,4,0,0,2,2], ...]
```

## 🚀 分步实现指南

### 第 1 步：游戏引擎核心（Python + Pygame 版）

```python
# engine/game.py
import pygame
import sys
import time

class Game:
    """游戏引擎核心 - 管理游戏循环"""

    def __init__(self, title: str = "MiniEngine",
                 width: int = 800, height: int = 600,
                 fps: int = 60):
        pygame.init()

        self.width = width
        self.height = height
        self.fps = fps
        self.screen = pygame.display.set_mode((width, height))
        pygame.display.set_caption(title)

        self.clock = pygame.time.Clock()
        self.running = False
        self.delta_time = 0.0

        # 系统管理
        self.systems = []
        self.scenes = {}
        self.current_scene = None

        # 事件管理
        self.event_handlers = {}

    def add_system(self, system):
        """添加 ECS 系统"""
        self.systems.append(system)
        return self

    def add_scene(self, name: str, scene):
        """注册场景"""
        self.scenes[name] = scene

    def switch_scene(self, name: str):
        """切换场景"""
        if self.current_scene:
            self.current_scene.on_exit()
        self.current_scene = self.scenes[name]
        self.current_scene.on_enter()

    def on(self, event_type: int, handler):
        """注册事件处理器"""
        if event_type not in self.event_handlers:
            self.event_handlers[event_type] = []
        self.event_handlers[event_type].append(handler)

    def run(self):
        """启动游戏循环"""
        self.running = True

        while self.running:
            # 计算 delta time
            self.delta_time = self.clock.tick(self.fps) / 1000.0

            # 1. 处理输入
            self._handle_events()

            # 2. 更新逻辑
            self._update()

            # 3. 渲染
            self._render()

        pygame.quit()
        sys.exit()

    def _handle_events(self):
        """处理系统事件"""
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                self.running = False
                return

            # 调用注册的事件处理器
            if event.type in self.event_handlers:
                for handler in self.event_handlers[event.type]:
                    handler(event)

        # 传递给当前场景
        if self.current_scene:
            self.current_scene.handle_events(pygame.event.get())

    def _update(self):
        """更新所有系统"""
        if self.current_scene:
            self.current_scene.update(self.delta_time)

        for system in self.systems:
            system.update(self.delta_time)

    def _render(self):
        """渲染"""
        self.screen.fill((0, 0, 0))  # 清屏

        if self.current_scene:
            self.current_scene.render(self.screen)

        for system in self.systems:
            if hasattr(system, 'render'):
                system.render(self.screen)

        pygame.display.flip()  # 交换缓冲区

    def quit(self):
        self.running = False
```

### 第 2 步：实体组件系统（ECS）

```python
# engine/ecs.py
from dataclasses import dataclass, field
from typing import Dict, List, Set, Type, Any
import pygame

# ---- 组件 ----

@dataclass
class Position:
    """位置组件"""
    x: float = 0.0
    y: float = 0.0

@dataclass
class Velocity:
    """速度组件"""
    vx: float = 0.0
    vy: float = 0.0

@dataclass
class Sprite:
    """精灵组件"""
    texture: pygame.Surface = None
    width: int = 32
    height: int = 32
    src_rect: pygame.Rect = None
    flip_x: bool = False
    flip_y: bool = False
    z_order: int = 0

@dataclass
class Collider:
    """碰撞体组件"""
    width: float = 32.0
    height: float = 32.0
    is_trigger: bool = False
    layer: str = "default"

@dataclass
class Animation:
    """动画组件"""
    frames: List[pygame.Surface] = field(default_factory=list)
    frame_duration: float = 0.1
    current_frame: int = 0
    elapsed: float = 0.0
    loop: bool = True

@dataclass
class Health:
    """生命值组件"""
    current: int = 100
    max_health: int = 100

@dataclass
class Input:
    """输入控制组件"""
    speed: float = 200.0


# ---- 实体 ----

class Entity:
    """实体 - 只是一个组件容器"""

    _next_id = 0

    def __init__(self, name: str = "Entity"):
        self.id = Entity._next_id
        Entity._next_id += 1
        self.name = name
        self.tags: Set[str] = set()
        self._components: Dict[Type, Any] = {}

    def add_component(self, component):
        """添加组件"""
        self._components[type(component)] = component
        return self

    def get_component(self, component_type):
        """获取组件"""
        return self._components.get(component_type)

    def has_component(self, *component_types) -> bool:
        """检查是否拥有指定组件"""
        return all(ct in self._components for ct in component_types)

    def remove_component(self, component_type):
        """移除组件"""
        self._components.pop(component_type, None)


# ---- 世界（World）----

class World:
    """世界 - 管理所有实体"""

    def __init__(self):
        self.entities: Dict[int, Entity] = {}

    def create_entity(self, name: str = "Entity") -> Entity:
        """创建实体"""
        entity = Entity(name)
        self.entities[entity.id] = entity
        return entity

    def destroy_entity(self, entity_id: int):
        """销毁实体"""
        self.entities.pop(entity_id, None)

    def query(self, *component_types) -> List[Entity]:
        """查询拥有指定组件的所有实体"""
        return [
            entity for entity in self.entities.values()
            if entity.has_component(*component_types)
        ]

    def get_by_tag(self, tag: str) -> List[Entity]:
        """按标签查找实体"""
        return [e for e in self.entities.values() if tag in e.tags]
```

### 第 3 步：系统实现

```python
# engine/systems.py
import pygame
from engine.ecs import *

class MovementSystem:
    """移动系统 - 处理所有有 Position + Velocity 的实体"""

    def update(self, dt: float, world: World):
        for entity in world.query(Position, Velocity):
            pos = entity.get_component(Position)
            vel = entity.get_component(Velocity)

            pos.x += vel.vx * dt
            pos.y += vel.vy * dt


class InputSystem:
    """输入系统 - 处理玩家输入"""

    def update(self, dt: float, world: World):
        keys = pygame.key.get_pressed()

        for entity in world.query(Position, Velocity, Input):
            vel = entity.get_component(Velocity)
            inp = entity.get_component(Input)

            vel.vx = 0
            vel.vy = 0

            if keys[pygame.K_LEFT] or keys[pygame.K_a]:
                vel.vx = -inp.speed
            if keys[pygame.K_RIGHT] or keys[pygame.K_d]:
                vel.vx = inp.speed
            if keys[pygame.K_UP] or keys[pygame.K_w]:
                vel.vy = -inp.speed
            if keys[pygame.K_DOWN] or keys[pygame.K_s]:
                vel.vy = inp.speed

            # 对角线移动归一化
            if vel.vx != 0 and vel.vy != 0:
                factor = 0.707  # 1/sqrt(2)
                vel.vx *= factor
                vel.vy *= factor


class RenderSystem:
    """渲染系统 - 绘制所有有 Position + Sprite 的实体"""

    def render(self, screen: pygame.Surface, world: World):
        # 收集所有可渲染实体并按 z_order 排序
        renderables = []
        for entity in world.query(Position, Sprite):
            pos = entity.get_component(Position)
            sprite = entity.get_component(Sprite)
            renderables.append((sprite.z_order, pos, sprite, entity))

        renderables.sort(key=lambda x: x[0])

        for z, pos, sprite, entity in renderables:
            if sprite.texture:
                # 翻转
                flipped = pygame.transform.flip(
                    sprite.texture, sprite.flip_x, sprite.flip_y
                )
                screen.blit(flipped, (int(pos.x), int(pos.y)))
            else:
                # 绘制占位矩形
                rect = pygame.Rect(int(pos.x), int(pos.y),
                                  sprite.width, sprite.height)
                pygame.draw.rect(screen, (255, 255, 255), rect)


class AnimationSystem:
    """动画系统"""

    def update(self, dt: float, world: World):
        for entity in world.query(Sprite, Animation):
            sprite = entity.get_component(Sprite)
            anim = entity.get_component(Animation)

            if not anim.frames:
                continue

            anim.elapsed += dt
            if anim.elapsed >= anim.frame_duration:
                anim.elapsed = 0
                anim.current_frame += 1

                if anim.current_frame >= len(anim.frames):
                    if anim.loop:
                        anim.current_frame = 0
                    else:
                        anim.current_frame = len(anim.frames) - 1

                sprite.texture = anim.frames[anim.current_frame]


class CollisionSystem:
    """碰撞检测系统"""

    def __init__(self):
        self.collision_callbacks = []

    def on_collision(self, callback):
        """注册碰撞回调"""
        self.collision_callbacks.append(callback)

    def update(self, dt: float, world: World):
        entities = world.query(Position, Collider)

        for i in range(len(entities)):
            for j in range(i + 1, len(entities)):
                a = entities[i]
                b = entities[j]

                if self._check_collision(a, b):
                    for callback in self.collision_callbacks:
                        callback(a, b)

    def _check_collision(self, a: Entity, b: Entity) -> bool:
        """AABB 碰撞检测"""
        pos_a = a.get_component(Position)
        col_a = a.get_component(Collider)
        pos_b = b.get_component(Position)
        col_b = b.get_component(Collider)

        # 检查碰撞层
        if col_a.layer != col_b.layer:
            return False

        # AABB 检测
        return (
            pos_a.x < pos_b.x + col_b.width and
            pos_a.x + col_a.width > pos_b.x and
            pos_a.y < pos_b.y + col_b.height and
            pos_a.y + col_a.height > pos_b.y
        )


class PhysicsSystem:
    """物理系统 - 简单的重力和碰撞响应"""

    def __init__(self, gravity: float = 980.0):
        self.gravity = gravity

    def update(self, dt: float, world: World):
        for entity in world.query(Position, Velocity):
            vel = entity.get_component(Velocity)
            # 应用重力
            vel.vy += self.gravity * dt

            # 速度限制
            max_vel = 800
            vel.vy = min(vel.vy, max_vel)
            vel.vy = max(vel.vy, -max_vel)


class CameraSystem:
    """摄像机系统 - 跟踪目标"""

    def __init__(self, screen_width: int, screen_height: int):
        self.x = 0
        self.y = 0
        self.screen_width = screen_width
        self.screen_height = screen_height
        self.target = None

    def follow(self, entity: Entity):
        """设置跟随目标"""
        self.target = entity

    def update(self, dt: float, world: World):
        if self.target:
            pos = self.target.get_component(Position)
            if pos:
                self.x = pos.x - self.screen_width // 2
                self.y = pos.y - self.screen_height // 2

    def apply(self, pos: Position) -> tuple:
        """将世界坐标转换为屏幕坐标"""
        return (int(pos.x - self.x), int(pos.y - self.y))
```

```python
# engine/tilemap.py
import pygame
from typing import List

class Tileset:
    """瓦片集"""

    def __init__(self, image_path: str, tile_width: int, tile_height: int):
        self.image = pygame.image.load(image_path).convert_alpha()
        self.tile_width = tile_width
        self.tile_height = tile_height
        self.tiles = self._split_tiles()

    def _split_tiles(self) -> dict:
        """将瓦片集图片分割为单独的瓦片"""
        tiles = {}
        img_width = self.image.get_width()
        img_height = self.image.get_height()

        tile_id = 0
        for y in range(0, img_height, self.tile_height):
            for x in range(0, img_width, self.tile_width):
                rect = pygame.Rect(x, y, self.tile_width, self.tile_height)
                tiles[tile_id] = self.image.subsurface(rect)
                tile_id += 1

        return tiles

    def get_tile(self, tile_id: int) -> pygame.Surface:
        return self.tiles.get(tile_id)


class Tilemap:
    """瓦片地图"""

    def __init__(self, tileset: Tileset, map_data: List[List[int]]):
        self.tileset = tileset
        self.map_data = map_data
        self.rows = len(map_data)
        self.cols = len(map_data[0]) if map_data else 0

    @classmethod
    def from_file(cls, filepath: str, tileset: Tileset) -> 'Tilemap':
        """从文件加载地图"""
        import json
        with open(filepath, 'r') as f:
            map_data = json.load(f)
        return cls(tileset, map_data)

    def render(self, screen: pygame.Surface, camera_x: int = 0, camera_y: int = 0):
        """渲染瓦片地图"""
        tw = self.tileset.tile_width
        th = self.tileset.tile_height

        # 只渲染屏幕可见区域内的瓦片
        start_col = max(0, camera_x // tw)
        start_row = max(0, camera_y // th)
        end_col = min(self.cols, (camera_x + screen.get_width()) // tw + 2)
        end_row = min(self.rows, (camera_y + screen.get_height()) // th + 2)

        for row in range(start_row, end_row):
            for col in range(start_col, end_col):
                tile_id = self.map_data[row][col]
                if tile_id >= 0:  # -1 表示空
                    tile = self.tileset.get_tile(tile_id)
                    if tile:
                        x = col * tw - camera_x
                        y = row * th - camera_y
                        screen.blit(tile, (x, y))

    def get_tile_at(self, world_x: float, world_y: float) -> int:
        """获取指定世界坐标的瓦片 ID"""
        col = int(world_x / self.tileset.tile_width)
        row = int(world_y / self.tileset.tile_height)
        if 0 <= row < self.rows and 0 <= col < self.cols:
            return self.map_data[row][col]
        return -1

    def is_solid(self, world_x: float, world_y: float) -> bool:
        """检查指定位置是否为固体瓦片"""
        tile_id = self.get_tile_at(world_x, world_y)
        # 假设 ID >= 100 的瓦片是固体
        return tile_id >= 100
```

### 第 6 步：完整游戏示例

```python
# main.py
"""MiniEngine 示例 - 简单的 2D 平台游戏"""
import pygame
from engine.game import Game
from engine.ecs import *
from engine.systems import *

def main():
    # 创建游戏实例
    game = Game(title="MiniEngine Demo", width=800, height=600, fps=60)
    world = World()

    # 创建系统
    input_system = InputSystem()
    movement_system = MovementSystem()
    render_system = RenderSystem()
    collision_system = CollisionSystem()

    # ---- 创建玩家 ----
    player = world.create_entity("Player")
    player.add_component(Position(x=400, y=300))
    player.add_component(Velocity())
    player.add_component(Sprite(width=32, height=32, z_order=10))
    player.add_component(Collider(width=32, height=32, layer="player"))
    player.add_component(Input(speed=200))
    player.tags.add("player")

    # ---- 创建一些障碍物 ----
    for i in range(5):
        obstacle = world.create_entity(f"Obstacle_{i}")
        obstacle.add_component(Position(x=100 + i * 150, y=400))
        obstacle.add_component(Sprite(width=64, height=64, z_order=5))
        obstacle.add_component(Collider(width=64, height=64, layer="obstacle"))
        obstacle.tags.add("obstacle")

    # ---- 注册碰撞回调 ----
    def on_collision(a, b):
        if "player" in a.tags and "obstacle" in b.tags:
            print(f"玩家碰撞了 {b.name}!")

    collision_system.on_collision(on_collision)

    # ---- 自定义渲染 ----
    def render_game(screen):
        # 绘制背景
        screen.fill((30, 30, 50))

        # 绘制网格
        for x in range(0, 800, 50):
            pygame.draw.line(screen, (40, 40, 60), (x, 0), (x, 600))
        for y in range(0, 600, 50):
            pygame.draw.line(screen, (40, 40, 60), (0, y), (800, y))

        # 渲染实体
        render_system.render(screen, world)

        # 绘制 HUD
        font = pygame.font.SysFont(None, 24)
        fps_text = font.render(f"FPS: {int(game.clock.get_fps())}", True, (255, 255, 0))
        entity_text = font.render(f"Entities: {len(world.entities)}", True, (255, 255, 0))
        screen.blit(fps_text, (10, 10))
        screen.blit(entity_text, (10, 35))

    # ---- 自定义更新 ----
    def update_game(dt):
        input_system.update(dt, world)
        movement_system.update(dt, world)
        collision_system.update(dt, world)

    # 挂载更新和渲染
    game._update = lambda: update_game(game.delta_time)
    game._render = lambda: render_game(game.screen)

    # 运行游戏
    game.run()

if __name__ == "__main__":
    main()
```
