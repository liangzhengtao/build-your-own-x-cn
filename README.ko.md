# 🛠️ Build Your Own X (중국어판)

**좋아하는 기술을 처음부터 다시 만들어 프로그래밍을 마스터하세요. 10개의 실습 튜토리얼.**

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

</div>

---

프로그래밍을 배우는 가장 좋은 방법은 **직접 해보는 것**입니다. 이론을 읽는 대신, 매일 사용하는 기술을 처음부터 다시 구축하세요.

이 프로젝트는 핵심 기술 — 운영체제, 데이터베이스, 웹 서버, 프로그래밍 언어 등을 처음부터 구축하는 **중국어 튜토리얼**의 큐레이션 컬렉션입니다. 각 튜토리얼에는 다음이 포함됩니다:

- 📖 핵심 개념에 대한 명확한 설명
- 💻 실행 가능하고 완전한 코드 예제
- 🧩 단계별 구현 가이드
- 🚀 고급 과제 및 추가 읽기

### 왜 "직접 만들어보기"인가요?

> "내가 만들 수 없는 것은 이해하지 못하는 것이다." — 리처드 파인먼

기술을 처음부터 구축함으로써 여러분은:
- API 호출을 넘어선 근본적인 원리를 깊이 이해하게 됩니다
- 체계적 사고와 아키텍처 설계 능력을 개발합니다
- 면접에서 기술적 깊이를 입증합니다
- 진정으로 전이 가능한 프로그래밍 능력을 얻습니다
